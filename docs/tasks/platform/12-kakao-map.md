# 12 카카오맵 JS SDK 연동 래퍼

## 목표

길찾기 화면(US-06)이 지도 SDK를 직접 다루지 않도록, 카카오맵 JS SDK를 감싼 지도 위젯을 `lib/core/`에 만든다.

## 할 일

- [ ] 카카오 개발자 앱 키 발급, 허용 도메인(로컬·운영) 등록
- [ ] Flutter Web에서 SDK 로드와 지도 렌더링(`HtmlElementView` + JS interop)
- [ ] SDK 기본 마커·경로 스타일은 쓰지 않고 오버레이로 그린다
  - 현재 위치: 경희블루 점
  - 목적지: 경희레드 핀
  - 경로: 경희레드 선(흰 외곽선)
- [ ] 경로는 서버가 준 좌표를 그린다. 카카오 도보 경로 조회는 REST API 키가 노출되지 않도록 백엔드가 하고, 프론트엔드는 SDK 로드와 지도 렌더링만 맡는다
  - 외부 경로 조회가 실패해도 서버는 200을 주고 `approximate: true`, `path`에 출발·도착 두 좌표만 담는다. 이때도 두 점을 이은 직선을 경로로 그린다
- [ ] 출발점과 목적지가 모두 보이도록 범위 맞추기
- [ ] 현재 위치 갱신(US-06은 10초 간격), '현재 위치로' 되돌리기
- [ ] 목적 건물 강조(US-06 B, Primary Tint)
- [ ] B가 Widget Test에서 실제 SDK 없이 쓸 수 있도록 인터페이스와 Fake 제공

## 완료 조건

- 로컬에서 핀·경로·현재 위치가 지도 위에 그려진다
- 래퍼 인터페이스에 대한 Fake와 그 사용 예시 테스트가 있다
