# 11 사진 크게 보기 화면

## 목표

후보 상세(US-04)와 관리자 공간 상세(AD-04)가 같은 방식으로 여는 전체 화면 사진 뷰어를 만든다.

## 결정

- OpenAPI 명세의 `photos`는 태그 코드 대신 `entrance`·`approach`·`inside`·`extras` 필드로 사진을 나눈다. `SpacePhoto.listFromJson`이 입구 · 가는 길 · 내부 · 추가 사진 순서의 목록으로 바꾸고, 추가 사진은 태그가 없다
- `approach`의 표시 문구는 '가는 길'이다. 명세 설명과 AD-03이 이 표현을 쓴다
- 뷰어는 경로 없이 `showPhotoViewer`로 현재 화면 위에 연다. 새로고침하면 닫힌 상태로 돌아간다

## 할 일

- [x] 입력: 사진 목록(`SpacePhoto`의 `url`, `tag`)과 시작 위치
- [x] 검은 배경 전체 화면, 누른 사진부터 연다
- [x] 좌우로 밀어 이전·다음 사진
- [x] 위쪽 가운데 `1 / 4` 위치 표시, 아래에 태그 이름(태그 없는 사진은 표시하지 않음)
- [x] 왼쪽 위 닫기(×) 또는 아래로 밀어 닫기. 조금만 밀면 제자리로 돌아온다
